# Vision

> Universal AI Website Navigator

## Overview

Vision is an AI-powered website navigation assistant designed to help users understand and navigate complex websites through natural language conversations.

Instead of manually searching through menus, pages, or documentation, users can ask questions such as:

- "Where can I find the refund policy?"
- "How do I apply for this position?"
- "Where is the pricing page?"

Vision uses Retrieval-Augmented Generation (RAG) to retrieve relevant information from website content and provide grounded, contextual responses.
