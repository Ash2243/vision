# Architectural Principles

The following principles should guide all future development:

- Build modular components.
- Keep services loosely coupled.
- Maintain clean separation of concerns.
- Prefer scalable architecture over short-term convenience.
- Every component should be replaceable without affecting the entire system.
- Keep the backend framework-agnostic wherever practical.
- Design with future RAG and multi-provider LLM support in mind.
